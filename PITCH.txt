DeciMap — Decentralized Noise Monitoring on Solana

Zurich receives over 6,500 noise complaints every year, but has virtually zero real-time monitoring infrastructure. Swiss law sets clear limits — 55 dB during the day, 45 dB at night — yet there's no data to enforce them. Complaints are filed, inspectors arrive days later, and the noise is long gone.

DeciMap fixes this by turning every smartphone into a noise sensor. Using the Web Audio API and GPS, anyone can measure ambient noise and submit a geotagged, timestamped reading directly to Solana. Reporters stake SOL to participate, readings are cross-validated by nearby users, and verified contributions earn rewards. Fraudulent data is auto-flagged and bad actors are slashed — making honesty the economically rational choice.

The data is sold to municipalities, urban planners, and real estate platforms — replacing expensive fixed sensors at a fraction of the cost. Built on Solana for sub-second finality and sub-cent transaction costs, DeciMap sits alongside Helium, Hivemapper, and Render in the growing DePIN ecosystem.

The project is fully open source (MIT), live as a demo, and built with Anchor (Rust) + React + TypeScript.
